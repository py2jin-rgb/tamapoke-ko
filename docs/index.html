⚡ 온라인 펌웨어 업데이트

✓ 한글 14/18/22px UI 폰트

✓ 한글+숫자/영문 혼합 문자열 깨짐 수정

✓ 하단 버튼 및 공놀이 터치 보정

✓ 공놀이 최고기록 한글 표시 수정

✓ 훈련 결과 최고기록 한글 표시 수정

중요: 기존 포켓몬을 유지하려면 전체 Erase/초기화를 선택하지 마세요. 이 설치기는 앱 영역 0x10000만 업데이트합니다.
PC용 Chrome 또는 Edge가 필요합니다. HTTPS 페이지에서 실행하세요.

USB 데이터 케이블로 연결 → 설치 버튼 → ESP32-S3/USB Serial 포트 선택 → 완료까지 기다리면 됩니다.

설치 순서

1. 다마포켓을 USB 데이터 케이블로 PC에 연결
2. 위의 안정판 설치 클릭
3. ESP32-S3 USB 포트 선택
4. Erase/초기화 질문이 나오면 기존 데이터 유지 선택
5. 설치 완료 후 재부팅되면 끝

처음 조립한 새 기기

이 페이지는 기존 TamaPoke 앱 업데이트용입니다. 완전 새 보드는 먼저 원작 TamaPoke의 부트로더/파티션과 microSD 스프라이트를 설치한 뒤 사용하세요.

🧪 TEST / 실험판 · ALARM v1.1

⏰ 알람 기능 테스트판

안정판과 별도로 빌드되는 알람 시험용 펌웨어입니다. 안정판 버튼과 파일이 완전히 분리되어 있어 알람판만 선택해서 시험할 수 있습니다.

✓ 안정판의 공놀이/훈련 최고기록 한글 보정 포함

✓ 대기화면 날짜 숫자 + 한글 요일 분리 렌더링

✓ 배터리 아이콘/퍼센트 원형 화면 안쪽으로 위치 보정

✓ 30초 미사용 시 시계 대기화면

✓ 알람 ON/OFF 및 시·분 설정

✓ 알람 울림 → 정지 / 5분 스누즈

✓ PWR 짧게 눌러 울리는 알람 정지

✓ 알람 설정값 NVS 저장

테스트판 주의: GitHub에서 컴파일 검증 후 공개하지만 실제 기기 동작은 실기 테스트 중입니다. Erase/초기화는 선택하지 마세요.

또한 PWR 짧게 눌러 화면만 끈 상태에서는 펌웨어가 계속 실행되어 알람이 동작하도록 설계했습니다. 완전히 전원을 차단한 상태에서는 알람 설정값은 유지되지만, ESP32가 꺼져 있으므로 알람이 울리는 기능은 보장하지 않습니다.
PC용 Chrome 또는 Edge가 필요합니다. HTTPS 페이지에서 실행하세요.

테스트 후 문제가 있으면 사진과 함께 알려주세요. 안정판은 위 버튼으로 언제든 다시 설치할 수 있습니다.
