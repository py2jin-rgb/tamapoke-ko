기존 ⑤ 2.6의 한글·육성·미니게임·통신 배틀·알람·음량 기능을 이어받고, 화면이 꺼진 동안 불필요한 표시·통신·오디오 작업을 줄이는 업데이트입니다.

  • 배터리 기본 모드: 무조작 30초 감광 → 2분 화면 꺼짐. 수동으로 연 시계에도 적용됩니다.
  • 꺼진 화면: 패널을 잠재우고 화면 전송을 멈춥니다. 터치·PWR·알람 복귀를 처리합니다.
  • 짧은 대기 절전: Light-sleep을 사용하며, USB 연결 중에는 적용하지 않습니다. 설정에서 끌 수 있습니다.

  • 통신과 소리: AP 설정·배틀 대기의 무기한 실행을 제한하고, 소리가 없을 때 오디오 장치를 쉬게 합니다.
  • 업데이트 검증: 새 OTA에서 인증서·파일 크기·SHA256을 확인합니다. 기존 저장 영역과 파티션 배치를 유지합니다.

실기 측정 상태: 배터리 지속시간과 평균 전류는 아직 실측하지 않았습니다. 사용시간·절감률은 측정 후 공개합니다.
