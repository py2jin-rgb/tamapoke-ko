# TamaPoke KO CLEAN v1.2

Waveshare ESP32-S3-Touch-AMOLED-1.75용 TamaPoke 비공식 한국어판 온라인 설치 저장소입니다.

- 펌웨어: `1.4-ko-clean1.2-restore-touch`
- 웹 설치: ESP Web Tools
- 업데이트 방식: 앱 영역(`0x10000`)만 기록
- 기존 NVS/세이브 및 microSD 스프라이트 유지
- 전체 Erase는 사용하지 마세요.

GitHub Actions가 검증된 소스 압축을 풀어 ESP32-S3용 앱 BIN을 자동 컴파일하고 GitHub Pages에 설치 페이지를 배포합니다.

온라인 설치 주소(배포 완료 후):

`https://py2jin-rgb.github.io/tamapoke-ko/`
